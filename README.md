# WEB Приложение для рынка

"Нашенский" рынок - это онлайн-платформа, созданная для удобного поиска товаров и услуг, а также для простого создания собственных предложений.

## Установка проекта
### 1. Клонируйте репозиторий и перейди в директорию проекта

```bash
git clone https://github.com/Nikitin-Elijah/NASH_Market.git
cd NASH_Market
```

### 2. Установите Poetry
В проекте используется менеджер пакетов poetry, и для успешной работы следует его установить
```bash
curl -sSL https://install.python-poetry.org | python3 -
```
Убедитесь, что poetry доступен в PATH
```bash
curl -sSL https://install.python-poetry.org | python3 -
```

### 3. Установите зависимости проекта
```bash
poetry install
```

## Настройка окружения
Создайте файл `.env` в корне проекта со следующим содержанием:
```env
DB_HOST = localhost
DB_USER = nash_market_user
DB_PASSWORD = db_password
DATABASE = nash_market_db
DB_PORT = 5432

S3_ACCESS_KEY=s3_access_key # ключ доступа к s3 хранилищу
S3_SECRET_KEY=s3_secret_key # секретный ключ s3 хранилища
ENDPOINT_URL=s3_storage_url # конечная точка s3 хранилища
BUCKET_NAME=bucket_name # имя "ведра" для хранения
STORAGE_URL=storage_url # ссылка на s3 хранилище

SECRET_KEY=secret_key # секретный ключ для регистрации и аутентификации 
```
Название базы данных и пароль можно поставить любым. В проекте используется s3 хранилище от компании selectel. Для создания своего хранилища перейдите на их сайт https://my.selectel.ru/


## Запуск системы
### Запустите все сервисы
```bash
docker-compose up --build  
```

## Миграция базы данных
### 1. Применение миграций
Чтобы применить миграции, необходимо запустить сервис с базой данных (если он не запущен). Далее для выполнения миграции необходимо выполнить
```bash
poetry run alembic upgrade head
```

### 2. Откат миграции
Если необходимо откатить последнюю миграцию, необходимо (при запущенном сервисе БД) выполнить
```bash
poetry run alembic downgrade -1
```

### 3. Создание миграции
Если необходимо создать миграцию, необходимо выполнить (при запущенном сервисе БД) выполнить
```bash
poetry run alembic revision --autogenerate -m "Migration description"
```

## Структура проекта
Проект имеет структуру:
```
NASH_Market/
│
├── backend/                        # Серверная часть приложения (FastAPI)
│   ├── migrations/                 # Файлы миграций базы данных (Alembic)
│   ├── src/                        # Исходный код бэкенда
│   │   ├── database/               # Настройки и подключение к базе данных
│   │   ├── models/                 # ORM-модели данных
│   │   ├── routers/                # API маршруты и endpoints
│   │   ├── s3_storage/             # Интеграция с облачным хранилищем S3
│   │   ├── schemas/                # Pydantic схемы для валидации данных
│   │   ├── auth.py                 # Аутентификация и авторизация (JWT)
│   │   ├── config.py               # Конфигурация приложения и переменные окружения
│   │   ├── main.py                 # Точка входа FastAPI приложения
│   │   └── utils.py                # Вспомогательные функции и утилиты
│   ├── alembic.ini                 # Конфигурация Alembic для миграций БД
│   ├── Dockerfile                  # Докерфайл для контейнеризации бэкенда
│   ├── poetry.lock                 # Фиксированные версии зависимостей Poetry
│   └── pyproject.toml              # Конфигурация зависимостей и метаданные проекта
├── frontend/                       # Клиентская часть приложения (HTML/CSS/JS)
│   ├── css/                        # Каскадные таблицы стилей
│   ├── images/                     # Статические изображения и иконки
│   ├── js/                         # JavaScript файлы для клиентской логики
│   ├── *.html                      # HTML Страницы
│   └── Dockerfile                  # Докерфайл для сборки фронтенда
├── nginx/                          # Конфигурация веб-сервера Nginx
├── .env                            # Переменные окружения и секреты
├── .gitignore                      # Игнорируемые Git файлы и папки
├── docker-compose.yml              # Оркестрация multi-container приложения
└── README.md                       # Документация проекта
```
